### 第三部分：如何高效将 Markdown 公式转为 Word 公式

Markdown 使用的是 LaTeX 语法（如 `\alpha + \beta`），Word 其实内置了 LaTeX 转换器，不需要安装额外插件。

**操作步骤（最快路径）：**

1.  **复制 LaTeX 代码**：
    从 Markdown 中复制公式代码，例如：
    `f(x) = \sum_{i=1}^{n} w_i x_i + b`
2.  **在 Word 中插入公式**：
    *   将光标放在要插入公式的地方。
    *   按下快捷键 **`Alt` + `=`** （这会调出公式编辑器）。
3.  **粘贴代码**：
    在公式框中粘贴刚才的代码。
4.  **转换**：
    *   **方法A（回车法）**：在代码末尾按一下 **`Enter`** 键，Word 会自动将其渲染为数学公式。
    *   **方法B（右键法）**：如果没变，点击公式框右下角的小箭头，选择“专业型” (Professional)。
    *   **注意**：确保 Word 公式编辑器的模式是“LaTeX”模式（在“公式”工具栏里可以看到“LaTeX”选项，选中它）。

**批量处理小技巧：**
如果你的 Markdown 里有大量的行内公式（如 `$x$`），一个个转太慢。
建议：
1.  先把 Markdown 文本纯文本粘贴到 Word。
2.  对于复杂的独立公式（Display Math），用上面的 `Alt+=` 方法。
3.  对于简单的变量（如 $N$, $t$），直接在 Word 里选中字母，按 `Ctrl + I` (斜体) 即可，或者用 `Alt+=` 快速输入。
