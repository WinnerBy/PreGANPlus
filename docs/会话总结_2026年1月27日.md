#### 故障检测机制详解

```python
# 故障检测的三个关键条件（均需同时满足）：

1. 资源超载条件（sustained overload）
   - CPU利用率 > 92% 且
   - RAM利用率 > 92%

2. 持续时间条件
   - 连续 ≥5 个时间间隔（每个间隔 300秒）
   - 约等于持续 ≥1500 秒的高负载

3. 活跃容器条件
   - 当前主机上必须有 ≥3 个活跃容器
   - 防止在低负载期间产生虚假故障报警
```

## 📝 关键代码片段

### 故障检测核心逻辑

```python
def detect_faults(self):
    """基于区间的故障检测"""
    fault_history = {}
    fault_interval_count = {}  # {host_id: count}
    
    for interval, host_metrics in enumerate(self.metrics_history):
        for host_id, metrics in host_metrics.items():
            cpu, ram, net = metrics
            
            # 检查资源超载
            if cpu > self.fault_config['cpu_threshold'] and \
               ram > self.fault_config['ram_threshold']:
                
                # 增加故障计数
                if host_id not in fault_interval_count:
                    fault_interval_count[host_id] = 1
                else:
                    fault_interval_count[host_id] += 1
                    
            else:
                # 重置故障计数
                fault_interval_count[host_id] = 0
            
            # 检查是否满足故障条件
            if fault_interval_count[host_id] >= \
               self.fault_config['min_fault_intervals']:
                
                # 检查最少容器要求
                active_containers = len(self.hosts[host_id].containers)
                if active_containers >= \
                   self.fault_config['min_active_containers']:
                    
                    fault_history[interval] = {
                        host_id: 'CPU_RAM_FAULT'
                    }
    
    return fault_history
```

### 性能指标计算

```python
def compute_overall_metrics(precisions, recalls, f1_scores):
    """计算聚合性能指标"""
    
    # 逐个指标计算
    p_mean = np.mean(precisions)
    p_std = np.std(precisions)
    p_min = np.min(precisions)
    p_max = np.max(precisions)
    
    r_mean = np.mean(recalls)
    r_std = np.std(recalls)
    r_min = np.min(recalls)
    r_max = np.max(recalls)
    
    f1_mean = np.mean(f1_scores)
    f1_std = np.std(f1_scores)
    
    # 综合F1-Score
    f1_combined = 2 * p_mean * r_mean / (p_mean + r_mean) \
                  if (p_mean + r_mean) > 0 else 0.0
    
    return {
        'precision': (p_mean, p_std, p_min, p_max),
        'recall': (r_mean, r_std, r_min, r_max),
        'f1_score': (f1_mean, f1_std, f1_combined)
    }
```

## 🎓 学习收获与最佳实践

### 故障检测系统设计原则

1. **多条件验证**：单一阈值容易产生误报，需组合多个条件
2. **时间连续性**：故障应该是持续的，而非瞬间的尖峰
3. **负载-特异性**：在低负载情况下避免报警
4. **可观测性**：保存故障历史便于审计和优化

### 机器学习模型训练的陷阱

1. **损失函数权重不平衡**：高权重会导致模型过度学习少数类
2. **阈值设置敏感**：百分位数、绝对值阈值需通过多轮实验调优
3. **数据分布差异**：仿真数据过于平滑，可能需要特殊处理

### 系统优化的迭代方法

- 从保守估计开始（v3），逐步放松约束
- 定量指标驱动：用故障检测率而非定性"感受"
- 保持可审计性：每个版本记录配置和结果
- 用单一维度迭代：每次只改一个参数，观察影响
