## 🎯 当前问题

### 性能瓶颈

| 指标 | 当前值 | 目标值 | 差距 |
|:---:|:---:|:---:|:---:|
| **Precision（精准率）** | 15.42% | ≥70% | 55% |
| **Recall（召回率）** | 68.31% | 60-70% | ✅ 达成 |
| **F1-Score** | 24.97% | 50%+ | 25% |

### 根本原因

**故障样本严重不足导致类别极度不平衡**：
- 总样本数：16,032 (1001 intervals × 16 hosts)
- 故障样本：291 (1.82%)
- 正常样本：15,741 (98.18%)
- **问题**：98:2的极度不平衡导致模型学习困难，任何权重调整都有极限

## 📊 Stage1 数据改进（最关键）

### 当前配置 vs 改进配置

| 参数 | 当前 | 改进 | 变化 |
|:---:|:---:|:---:|:---:|
| `NUM_SIM_STEPS` | 1000 | **2000** | 2倍 |
| `NEW_CONTAINERS` | 5 | **15** | 3倍 |
| 预期故障率 | 1.82% | **15-25%** | 8-14倍 |
| 故障样本数 | 291 | **~3000+** | 10倍+ |

### 为什么改进这些参数？

```
更多容器 (5→15) → 系统负载增加
                 → 更容易超过CPU/RAM 90%阈值
                 → 更容易触发故障检测机制
                 
更长模拟时间 (1000→2000)
           → 更多机会形成5-interval连续超限
           → 更多故障样本
           
结果: 类别不平衡从98:2 → 80:20（大幅改善）
```

### 执行命令

```bash
# 立即执行改进的数据生成
python scripts/stage1_data_generation_improved.py --steps 2000 --new-containers 15

# 验证故障率（预期15-25%）
python -c "
import pickle
with open('recovery/PreGANSrc/data/simulator/fault_history.pkl', 'rb') as f:
    fh = pickle.load(f)
total = (max(fh.keys())+1) * 16
faults = sum(len(v) for v in fh.values())
print(f'总样本: {total}')
print(f'故障样本: {faults}')
print(f'故障率: {faults/total*100:.2f}%')
"
```

**预期耗时**: 60-90分钟

## 🔧 快速参考

### 关键概念

**故障检测机制**（基于ADE逻辑）：
```python
IF (CPU > 90% AND RAM > 90%) AND (持续 ≥5个interval) 
THEN: 标记为故障
```

**为什么需要足够的故障样本**：
- 机器学习在极度不平衡数据(98:2)下很难学习
- 即使用Focal Loss和权重调整也有极限
- **解决方案**：增加故障样本使其达到10-25%范围

### 文件位置

```
核心训练脚本:
- recovery/PreGANSrc/src/train.py          (训练逻辑+权重)
- recovery/PreGANSrc/src/constants.py      (超参数)
- recovery/PreGANSrc/src/utils.py          (数据加载+标签生成)
- recovery/PreGANSrc/src/models.py         (FPE模型)

数据生成脚本:
- scripts/stage1_data_generation_improved.py (高故障率数据生成)
- scripts/stage2_model_training.py          (编码器训练)

训练数据:
- recovery/PreGANSrc/data/simulator/
  ├── time_series.npy           (时间序列数据)
  ├── schedule_series.npy       (调度决策)
  └── fault_history.pkl         (故障历史标签)
```

## 💡 核心原理

### 为什么增加故障样本就能解决问题？

```
原理：类别不平衡是根本问题
        ↓
当前状态(98:2)：模型学会"总是预测正常"
        ↓
虽然准确率98%，但精准率只有6.67%
（因为分母太小——预测的故障太少）
        ↓
改进状态(80:20)：模型充分学习异常特征
        ↓
精准率提升到50-70%（3-5倍提升）
```

### 为什么调整参数还不够？

| 技术 | 有效范围 | 当前状态 | 能否解决 |
|:---:|:---:|:---:|:---:|
| 权重调整 | 90:10 ~ 95:5 | 98:2 | ❌ 超出范围 |
| Focal Loss | 95:5 ~ 97:3 | 98:2 | ❌ 超出范围 |
| 过采样 | 95:5 | 98:2 | ⚠️ 有限 |
| **增加故障样本** | **任何比例** | **98:2** | **✅ 完全解决** |
