# Stage1 数据生成改进方案

**创建日期**: 2026年1月28日  
**目标**: 通过增加故障样本数量，将故障率从1.82%提升到15-25%

---

## 🔍 问题分析

### 当前数据的类别不平衡问题

| 指标 | 数值 |
|:---:|:---:|
| 总样本数 | 16,032 (1001 intervals × 16 hosts) |
| 故障样本数 | 291 |
| **故障率** | **1.82%** |
| 正常样本数 | 15,741 |
| 正常率 | 98.18% |

**问题**：98%正常 vs 2%异常导致模型学习困难
- 编码器容易学会"总是预测正常"（准确率达98%，但精准率仅6.67%）
- 即使用ANOMALY_WEIGHT和Focal Loss也难以充分补偿

### 故障率对模型性能的影响

根据机器学习理论，类别不平衡比例越高，模型越难学习：

| 不平衡比例 | 难度 | 推荐解决方案 |
|:---:|:---:|:---|
| 50:50 | 容易 | 标准训练 |
| 90:10 | 中等 | 权重调整、过采样 |
| 95:5 | 困难 | 权重调整 + Focal Loss |
| **98:2** | **极困难** | **根本不足，需要数据增强** |

**结论**：1.82%的故障率已经超出传统不平衡学习的有效范围，**必须通过生成更多故障样本来解决**。

## 📊 改进方案对比

### 当前配置（Stage1基础版）

```python
NUM_SIM_STEPS = 1000        # 1000个时间步
NEW_CONTAINERS = 5          # 每步新增5个容器
总容器数 = 1000 × 5 = 5000
预期故障率 = 1.82% (实际: 291/16032)
```

**分析**：
- 每步仅5个容器，总体负载较低
- 容器在系统中停留时间较短，不容易触发长期故障

### 改进配置（Stage1改进版）

```python
NUM_SIM_STEPS = 2000        # 2000个时间步（2倍）
NEW_CONTAINERS = 15         # 每步新增15个容器（3倍）
总容器数 = 2000 × 15 = 30000（6倍）
预期故障率 = 15-25%
```

**预期改进**：
- 容器负载大幅增加（5→15，3倍）
- 模拟时间加长（1000→2000，2倍）
- 更容易触发CPU/RAM超限的故障

### 故障生成机制

故障通过**ADE（Anomaly Detection Engine）**自动检测，基于：

```python
IF (CPU_usage > 90%) AND (RAM_usage > 90%) AND (持续 ≥ 5个interval)
THEN: 标记为故障
```

**改进配置的效果**：
- 更多容器 → 更高的CPU/RAM使用率
- 更长的模拟时间 → 更多机会触发5-interval连续超限
- 结果：故障样本数预期增加 10-15倍

## ⚡ 预期性能改善

### 数据改进带来的模型性能提升

假设改进后故障率达到20%（vs原来的1.82%）：

| 方面 | 原始配置 | 改进配置 | 改善 |
|:---:|:---:|:---:|:---:|
| **故障样本数** | 291 | ~3200 | **11倍** |
| **不平衡比例** | 98:2 | 80:20 | **大幅改善** |
| **Focal Loss有效性** | 有限 | **有效** | **显著** |
| **预期Precision** | 15% | **50-70%** | **3-5倍** |

### 改进的优势

1. ✅ **根本解决类别不平衡**
   - 从极端不平衡(98:2)到合理不平衡(80:20)
   - 模型可以充分学习异常特征

2. ✅ **充分利用Focal Loss**
   - 当故障样本足够多时，Focal Loss才能有效工作
   - 预期精准率提升5-10倍

3. ✅ **论文更有说服力**
   - 更平衡的训练数据
   - 更高的精准率（目标70%+）
   - 更可信的实验结果

4. ✅ **充分利用模型容量**
   - 当前模型在1.82%故障率下严重欠拟合
   - 改进后可以充分学习

## ⚠️ 风险和考虑

### 可能的调整

如果改进后的故障率不理想：

**情况1：故障率仍然太低（<10%）**
```python

```

**情况2：故障率过高（>30%）**
```python

python scripts/stage1_data_generation_improved.py --steps 3000 --new-containers 12
```

### 模型稳定性

- 当故障率在10-25%范围内时，标准的不平衡学习技术最有效
- 超过30%则退化为标准多分类问题
