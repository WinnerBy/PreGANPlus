# 结论

随着边缘计算在物联网与实时服务场景中的广泛部署，边缘侧普遍面临资源受限、负载高动态波动与故障频发等问题，使得在 QoS 与能耗约束下实施容器抢占式迁移成为保障服务连续性的重要手段。然而，迁移决策同时受到时空相关性、多目标冲突以及运行环境不确定性等因素的共同作用，传统启发式方法往往难以在多维指标之间获得稳定且可控的权衡。本文围绕故障风险表征、迁移决策生成与多目标约束引导等关键环节，研究了基于生成对抗网络的主动容错迁移机制，并通过 FPE-GAN、TF-GAN 与 MAMO-GAN 的渐进式演进，形成了一套相对完整的方法体系。

本文的主要工作总结如下：

（1）针对边缘环境中故障风险信号具有时序依赖与拓扑相关、且决策空间较大的特点，本文提出基于深度生成模型的抢占式迁移主动容错框架。该框架通过时空特征编码实现故障风险刻画，并在异常检测触发条件下生成候选迁移调度；随后结合仿真评估与保守筛选机制过滤低收益迁移。在既定仿真环境与工作负载设置下，本文对能耗、响应时间、SLA 合规性与迁移规模等指标进行了联合评估。实验结果表明，相较部分传统启发式方法，GAN 系列方法整体具有更低的迁移规模，迁移次数降幅约为 **4%–63%**，体现了生成式决策在迁移规模控制方面的潜力。

（2）针对长序列依赖建模不足与决策稳定性不易保证的问题，本文在 TF-GAN 中引入 Transformer 编码器，提升时序表征的并行性与可扩展性，并为后续方法扩展提供更稳定的结构基础。对比实验表明，引入 Transformer 后，TF-GAN 能够提升迁移决策的稳定性，为多目标扩展提供了更可靠的表征支撑。

（3）针对能耗、响应时间与迁移成本等多目标之间的冲突关系，本文在 MAMO-GAN 中引入迁移感知生成器与多目标判别器，使多维 QoS 约束与迁移成本能够在训练过程中获得联合反馈与约束，从而在多目标冲突条件下实现更可控的权衡。同时，本文结合图注意力网络（GAT）与序列模型，实现对时间依赖与空间依赖的联合建模，以增强对复杂边缘拓扑与动态负载的适应性。实验结果表明，在方法内部对比中，MAMO-GAN 相较 TF-GAN 的总能耗降低约 0.5%，迁移次数及其方差进一步减小，SLA 违约率稳定在约 12.83%，说明多目标约束引导与迁移感知机制有助于在多维指标之间实现更稳定、可控的权衡关系。

此外，本文在 MAMO-GAN 基础上设计并开展消融实验，分别移除 Transformer、GAT、迁移感知机制与多目标判别器等关键组件，构建四种消融模型。结果表明，MAMO-GAN 在“少迁移、低波动”的迁移控制与能耗优化方面具有优势。其中，GAT 主要支撑对节点空间关联与全局资源分配关系的建模，从而提升迁移决策稳定性并抑制迁移规模；迁移感知机制进一步强化对迁移成本的约束，使策略运行过程中更不易出现不必要的频繁迁移；多目标判别器为能耗等目标提供更直接的反馈信号，使生成过程在多目标冲突下仍能保持相对一致的优化方向；Transformer 则增强了故障风险的时序表征能力，为迁移决策的稳定性与有效性奠定基础。

尽管本文方法取得了一定进展，但仍存在如下局限性：第一，GAN 模型收敛通常需要较大的计算资源与时间成本，尽管推理阶段相对高效，但在线训练或再训练对边缘侧算力仍构成挑战；第二，实验主要依托 COSCO 仿真平台，仿真环境难以完全复现物理网络中的抖动、丢包以及容器冷启动等复杂系统行为；第三，MAMO-GAN 涉及多目标权重 $$\lambda$$、Transformer 层数等超参数，静态参数配置对极端多变场景的自适应能力仍有限；第四，本文主要关注资源过载引起的软故障，对硬件损坏、断电或网络链路中断等硬故障场景的覆盖仍有待完善。

总体而言，本文面向边缘环境抢占式迁移构建了生成式主动容错方法体系，通过时空特征建模、生成式候选决策构造与多目标约束引导，在多维性能指标之间实现了相对稳定的权衡，并通过对比实验与消融实验验证了关键机制的有效性。

未来工作可重点从两方面推进：其一，面向负载突变与故障模式漂移，探索在线适配与自调参机制以增强方法的场景自适应能力；其二，引入数字孪生等手段缩小仿真与真实系统差距，在低风险条件下完成训练验证并逐步迁移到真实部署环境。
