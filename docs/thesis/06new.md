

# 结论

随着边缘计算在物联网与实时服务场景中的广泛部署，边缘侧资源受限、负载高动态波动以及故障频发等问题，使得面向 QoS 与能耗约束的容器抢占式迁移成为保障服务连续性的关键手段。然而，迁移决策同时受到时空相关性、多目标冲突以及运行环境不确定性等因素的共同影响，传统启发式方法往往难以在多维指标之间获得稳定权衡。本文围绕“故障风险表征—迁移决策生成—多目标约束引导”的技术链路，研究了基于生成对抗网络的主动容错迁移机制，并在 FPE-GAN、TF-GAN 与 MAMO-GAN 的渐进式演进中形成了较为完整的方法体系。

本文的主要工作如下：

（1）针对边缘环境中故障风险信号具有时序依赖与拓扑相关、且决策空间较大的特点，本文提出了基于深度生成模型的抢占式迁移主动容错框架，通过“故障风险感知—异常触发—生成并筛选候选调度”的闭环设计，在既定仿真环境与工作负载设置下对能耗、响应时间、SLA 合规性与迁移规模等指标开展联合评估，为数据驱动方法在复杂边缘调度问题中的可行性提供了验证基础。实验结果表明，在与部分传统启发式方法的对照中，GAN 系列方法在迁移规模上整体更低，迁移次数的降幅约在 **4%–63%** ，体现了生成式决策在迁移规模控制方面的潜力。

（2）针对长序列依赖建模与决策稳定性问题，本文在 TF-GAN 中引入 Transformer 编码器，提升了时序表征的并行性与可扩展性，并为后续方法扩展提供了更稳定的结构基础；其改进效果主要体现在对迁移决策稳定性的影响。实验对比表明，TF-GAN 在引入 Transformer 后能够提升迁移决策的稳定性，为后续多目标扩展提供了更可靠的表征基础。

（3）针对能耗、响应时间与迁移成本等多目标之间的冲突关系，本文在 MAMO-GAN 中引入迁移感知生成器与多目标判别器，使多维 QoS 约束与迁移成本在训练过程中得到联合反馈与约束，从而在多目标冲突下形成更可控的权衡；同时结合图注意力网络（GAT）与序列模型实现对时间依赖与空间依赖的联合建模，以增强对复杂边缘拓扑与动态负载的适应性。实验结果表明，在方法内部对比中，MAMO-GAN 相较 TF-GAN 的总能耗降低约 0.5%，迁移次数与其方差进一步减小，SLA 违约率稳定在约 12.83%，说明多目标约束引导与迁移感知机制有助于在多维指标之间形成更可控的权衡。

此外，本文在 MAMO-GAN 的基础上进一步设计了消融实验，分别取消 Transformer、GAT、迁移感知机制与多目标判别器等关键组件，构造了四种消融模型。消融实验表明，本文提出的 MAMO-GAN 在“少迁移、低波动”的迁移控制与能耗优化等方面具有优势。其中，GAT 主要支撑了对节点空间关联的建模与全局资源分配，从而提高迁移决策的稳定性并抑制迁移规模；迁移感知机制进一步增强了对迁移成本的约束，使得策略在运行过程中更不易出现不必要的频繁迁移；多目标判别器为能耗等目标提供了更直接的反馈信号，使生成过程能够在多目标冲突下保持相对一致的优化方向；Transformer 则为故障风险的时序表征提供了更强的建模能力，为后续迁移决策的稳定性与有效性奠定基础。

尽管本文方法取得了一定进展，但仍存在局限性：一是 GAN 模型收敛通常需要较大计算资源与时间成本，推理阶段虽较高效，但在线训练或再训练（Re-training）对边缘侧算力仍构成挑战；二是实验主要依托 COSCO 仿真平台，仿真环境难以完全复现物理网络中的抖动、丢包以及容器冷启动等复杂系统行为；三是 MAMO-GAN 涉及多目标权重 $\lambda$、Transformer 层数等超参数，静态参数配置对极端多变场景的自适应能力仍有限；四是本文主要关注资源过载引起的软故障，对硬件损坏、断电或网络链路中断等硬故障场景的覆盖仍有待完善。

总体而言，本文构建了面向边缘环境抢占式迁移的生成式主动容错方法体系，通过时空特征建模、生成式候选决策构造与多目标约束引导，在多维性能指标之间实现了相对稳定的权衡，并通过第5章的对比实验与消融实验验证了所提关键机制的有效性。

未来的研究可进一步从两方面展开：一方面，可探索更强的在线适配与自调参机制，提升方法对负载突变与故障模式漂移的适应能力；另一方面，为弥补仿真与现实的鸿沟，可引入数字孪生技术，在数字孪生体中进行低成本训练与验证，并将模型与策略同步到物理系统以降低真实环境“试错”风险。此外，面向无服务器（Serverless）架构的函数级细粒度调度，以及面向绿色边缘计算的碳感知调度目标，也将为本文方法体系的扩展提供更具现实意义的应用方向。
