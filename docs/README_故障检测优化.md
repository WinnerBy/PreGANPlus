## 📋 关键约束条件

1. **保持模型结构主要类型不变**
   - FPE-GAN: GRU+GAT
   - TF-GAN/MAMO-GAN: Transformer

2. **故障定义要有物理意义**
   - 基于论文中的ADE定义
   - 90%阈值 + 持续60秒
   - 能在论文中合理解释

---

## 🚀 推荐实施顺序

1. **阶段1**：实现ADE故障定义（精确度 16% → 35-50%）
2. **阶段2**：概率性故障放大（精确度 35-50% → 50-65%）
3. **阶段3**：噪声注入（精确度 50-65% → 55-70%）
